# Streaming Spend Inference

🇧🇷 **Leia em português:** [README.pt-BR.md](README.pt-BR.md)

Inferential statistics, step by step, on the spending of 100,000 streaming-platform customers: simple random sampling, confidence interval, sample size, the sampling distribution of the mean and a hypothesis test.

This is a course assignment for *Estatística Indutiva* (Inferential Statistics), Data Science program, Fatec Baixada Santista Rubens Lara. The goal is to understand and practice each step, not only to get the numbers.

## What this project covers

| Part | Topic | Core idea |
|---|---|---|
| 1 | Pilot sample | Simple random sample (SRS) of 25 customers; table, mean and variance (divisor n − 1) |
| 2 | Confidence interval | 95% CI for the mean with unknown variance (t distribution, ν = n − 1) |
| 3 | Sample size | n = z² · s² / ε², with ε = R$ 50.00 and 95% confidence, rounded up |
| 4 | Sampling distribution of the mean | 100 samples; mean and standard deviation of the 100 sample means vs. σ/√n (Central Limit Theorem) |
| 5 | Hypothesis test | Two-sided test for μ = R$ 800.00, known σ = 387, α = 5% |

The full statement is in [`docs/`](docs/): the original in Portuguese ([`atividade-pratica-1.pt-BR.md`](docs/atividade-pratica-1.pt-BR.md)) and an unofficial English translation ([`assignment-1.en.md`](docs/assignment-1.en.md)).

## Approach

The solutions follow the method taught in the course, so that every result can be reproduced by hand:

- critical values are read from the printed tables (standard normal, Student's t); the software value is shown only as a cross-check;
- degrees of freedom are ν = n − 1, and the sample variance uses the divisor n − 1;
- the sample size n is always rounded **up**;
- samples are drawn by SRS **without replacement**, with a fixed seed for reproducibility;
- the critical region of a test is written on the scale of the sample mean, and the conclusion is stated in the language of the problem.

Code supports the explanation; it does not replace it.

## Data

The dataset (`clientes_plataforma_Streaming.csv`, 100,000 rows) is course material, included in [`data/`](data/) so that every result can be reproduced. It remains the property of the course; if its owner asks, it will be removed. See [`data/README.md`](data/README.md) for the columns.

## How to run

You only need R (version 4 or later). The scripts are written to run with base R, without extra packages, whenever possible.

- **Locally:** install R and run the scripts in `R/` from the repository root (they read `data/clientes_plataforma_Streaming.csv`).
- **Google Colab:** open a notebook from `notebooks/`, then choose *Runtime → Change runtime type → R*.
