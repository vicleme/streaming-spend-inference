# Data / Dados

**English**

`clientes_plataforma_Streaming.csv` is the course dataset (100,000 customers of a streaming platform). It is course material, included here so the results can be reproduced; if its owner asks, it will be removed. Files generated by the scripts (for example `piloto_25.csv`, the pilot sample) are saved in this folder too.

Columns (header exactly as in the file; R is case-sensitive, so `Gasto_reais` is not `gasto_reais`):

| Column | Meaning |
|---|---|
| `Cliente_ID` | customer identifier (1 to 100000) |
| `Tempo_permanencia_horas` | time spent on the platform, in hours |
| `Gasto_reais` | customer spending, in R$ (the variable studied) |

**Português**

`clientes_plataforma_Streaming.csv` é a base da disciplina (100.000 clientes de uma plataforma de streaming). É material da disciplina, incluído aqui para que os resultados possam ser reproduzidos; se o responsável pedir, será removido. Os arquivos gerados pelos scripts (por exemplo `piloto_25.csv`, a amostra-piloto) também são salvos nesta pasta.

As colunas estão na tabela acima. Atenção: o R diferencia maiúsculas de minúsculas, então `Gasto_reais` não é `gasto_reais`.
